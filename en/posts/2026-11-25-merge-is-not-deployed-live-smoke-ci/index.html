Merged Is Not Shipped: Building a Zero-Token Post-Merge Live Smoke CI for Multi-Site Static Fleets

For your AI: this post ships with a runnable, desensitized agent edition — English · 中文版

1. Merged Does Not Mean Users Can Open It

When running multiple static products in parallel—a portal, a technical blog, a GPU price tracker, and client-side micro-tools—it is dangerously easy to treat "PR merged" as the finish line.

Running an automated live HTTP sweep across every public route caught two real production gaps immediately:

  • Silent HTTP 404 on new sub-routes: The private source repo merged the new page, but its cross-repo deploy workflow only listened to workflow_dispatch and a daily cron—missing push: branches: [main]—leaving the public GitHub Pages repo stale for hours.
  • HTTP 000 on newly launched domains: A staged micro-tool still had private visibility and pending DNS/Pages wiring, so TLS didn't even complete yet.

Until a zero-token check hits the actual HTTPS endpoint and verifies HTTP 200 plus an expected DOM marker, closure is guesswork.

4. Zero-Dependency Code & Workflows

1. Multi-Site Live Smoke Checker (scripts/live_smoke.py)

#!/usr/bin/env python3
# Zero-dependency Post-Merge Live Smoke Checker for multi-site static fleets.
from dataclasses import dataclass
import sys
import time
import urllib.error
import urllib.request

@dataclass(frozen=True)
class SmokeTarget:
    name: str
    url: str
    expected_status: int = 200
    required_marker: str = ""

TARGETS = [
    SmokeTarget("Portal", "https://plaigroundlab.com/", 200, "PlAIground Lab"),
    SmokeTarget("Blog", "https://blog.plaigroundlab.com/", 200, "AI Geek Blog"),
    SmokeTarget("ComputeQuote", "https://computequote.plaigroundlab.com/", 200, "ComputeQuote"),
    SmokeTarget("Calculator", "https://computequote.plaigroundlab.com/calculator/", 200, "Payback Calculator"),
]

def probe(target: SmokeTarget, timeout: float = 12.0) -> bool:
    req = urllib.request.Request(
        target.url,
        headers={"User-Agent": "PlAIgroundLab-LiveSmoke/1.0 (+https://plaigroundlab.com)"},
    )
    t0 = time.monotonic()
    try:
        with urllib.request.urlopen(req, timeout=timeout) as resp:
            status = int(resp.getcode() or 0)
            body = resp.read().decode("utf-8", errors="replace")
            ms = round((time.monotonic() - t0) * 1000.0, 1)
            ok = (status == target.expected_status) and (target.required_marker.lower() in body.lower())
            print(f"[{'PASS' if ok else 'FAIL'}] {status} ({ms}ms) {target.name} -> {target.url}")
            return ok
    except urllib.error.HTTPError as e:
        print(f"[FAIL] {e.code} {target.name} -> {target.url}", file=sys.stderr)
        return False
    except Exception as e:
        print(f"[FAIL] 000 ({e}) {target.name} -> {target.url}", file=sys.stderr)
        return False

if __name__ == "__main__":
    results = [probe(t) for t in TARGETS]
    raise SystemExit(0 if all(results) else 1)

2. Path-Filtered Publish Workflow + Post-Deploy Verification

name: Publish Site & Verify Live
on:
  workflow_dispatch: {}
  push:
    branches: [main]
    paths:
      - "web/**"     # Avoid burning CI minutes on docs or script-only commits

jobs:
  deploy-and-verify:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: "20"
      - run: cd web && npm ci && npm run build
      - name: Deploy & Verify Live Routes
        run: |
          sleep 30
          python3 scripts/live_smoke.py

3. Local Ephemeral Server Unit Test (Network-Free CI)

import http.server
import threading
import unittest

class SmokeServerTest(unittest.TestCase):
    def test_catches_404_and_200(self):
        srv = http.server.ThreadingHTTPServer(("127.0.0.1", 0), _Handler)
        t = threading.Thread(target=srv.serve_forever, daemon=True)
        t.start()
        try:
            port = srv.server_address[1]
            self.assertTrue(probe(SmokeTarget("ok", f"http://127.0.0.1:{port}/ok", 200, "Calculator")))
            self.assertFalse(probe(SmokeTarget("404", f"http://127.0.0.1:{port}/missing", 200, "Calculator")))
        finally:
            srv.shutdown()
            srv.server_close()

5. Three Real Production Gotchas

  1. Missing workflow PAT scope blocks workflow edits mid-PR: Automated PR generators often lack permission to update .github/workflows/. Build an explicit fallback that preserves static site assets cleanly while surfacing the workflow diff for maintainer review.
  2. Default Python-urllib User-Agent hits edge HTTP 403: Edge firewalls commonly drop bare Python library agents even while curl gets HTTP 200. Always set a clear custom User-Agent header in health probes.
  3. Unfiltered on: push workflows waste Actions minutes: Always scope site build triggers with paths: ['web/**'] so data-only or doc commits never re-run full Node builds.
