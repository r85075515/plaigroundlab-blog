Cutting Always-On Agent Context by 80% (101 KB to 20 KB) Without Amnesia: Progressive Disclosure & Anti-Bloat Watchdogs

For your AI: this post ships with a runnable, desensitized agent edition — English · 中文版

1. Why a 101 KB "Complete Manual" Makes AI Agents Forget More

Almost every autonomous agent setup starts with the same reflex: whenever a script fails or a policy gets clarified, someone appends another paragraph to the permanent system prompt or MEMORY.md. Within weeks, boot context files quietly ballooned to 101.2 KB.

Counterintuitively, stuffing everything into always-on context caused three immediate failures:

  • 25,000+ tokens replayed every turn: Even a trivial status check had to pay full prompt tax, draining rate-limited windows fast.
  • Lost-in-the-middle rule blindness: Critical safety constraints got buried inside pages of stale troubleshooting stories.
  • Fear of deleting: Editing a giant prose manual risks wiping settled ports, IDs, or acceptance thresholds.

Our fix was Progressive Disclosure + Deterministic Budget Enforcement: keep boot files strictly under 20.4 KB (~80% smaller) via explicit action-pointer tables while moving domain SOPs into lazy-loaded runbooks.

4. Desensitized Runnable Code & Configs

1. Declarative Context Routing & Hard Caps

# context_budget.yaml — explicit thresholds, zero magic numbers
boot_files:
  - path: AGENTS.md
    max_bytes: 12288     # Hard 12 KB ceiling
    max_lines: 220
  - path: MEMORY.md
    max_bytes: 14336     # Hard 14 KB ceiling
    max_lines: 260

pointer_routes:
  - trigger: "deploy | pages | release"
    load: "docs/runbooks/deploy-and-smoke.md"
  - trigger: "schema | spreadsheet | ingest"
    load: "docs/runbooks/data-pipeline.md"
  - trigger: "budget | quota | incident"
    load: "docs/runbooks/ops-guardrails.md"

2. Zero-Token Anti-Bloat CI Guard (Python Stdlib Only)

#!/usr/bin/env python3
# Zero-token watchdog enforcing hard byte/line budgets on always-on agent files.
from pathlib import Path
import sys

BUDGETS = {
    "AGENTS.md": {"max_bytes": 12288, "max_lines": 220},
    "MEMORY.md": {"max_bytes": 14336, "max_lines": 260},
}

def check_repo_budgets(root: Path) -> int:
    failures = []
    for rel, limits in BUDGETS.items():
        target = root / rel
        if not target.exists():
            failures.append(f"MISSING: {rel}")
            continue
        raw = target.read_bytes()
        lines = raw.decode("utf-8", errors="replace").splitlines()
        if len(raw) > limits["max_bytes"]:
            failures.append(f"OVERSIZE: {rel} = {len(raw)} B > {limits['max_bytes']} B (move details to runbooks/)")
        if len(lines) > limits["max_lines"]:
            failures.append(f"OVERLINE: {rel} = {len(lines)} lines > {limits['max_lines']}")
        else:
            print(f"OK: {rel} ({len(raw)} B, {len(lines)} lines)")

    if failures:
        for msg in failures:
            print(f"FAIL: {msg}", file=sys.stderr)
        return 1
    return 0

if __name__ == "__main__":
    raise SystemExit(check_repo_budgets(Path(".")))

3. Path-Filtered GitHub Actions Gate

name: Agent Context Budget Gate
on:
  pull_request:
    paths:
      - "AGENTS.md"
      - "MEMORY.md"
      - "docs/runbooks/**"

jobs:
  verify-budget:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Run 0-token budget check
        run: python3 scripts/context_watchdog.py

5. Three Real Production Pitfalls We Fixed

  1. Accidental masking of real SSOT identifiers: Early slimming drafts accidentally replaced concrete IDs and canonical endpoints with generic placeholders, causing agents to pick stale copies on later turns. Rule: keep exact canonical IDs, thresholds, and non-secret SSOT values inside the index; move only multi-step prose into runbooks.
  2. In-place overwrites without immutable rollback snapshots: Never rewrite boot context blindly. Always write original byte counts and SHA-256 checksums to an untouched backup snapshot before applying slimming waves.
  3. One-off cleanups without an automated CI ceiling: Without a failing CI gate when AGENTS.md crosses 12 KB, "just three quick lines" brings the 100 KB bloat right back within two weeks.
