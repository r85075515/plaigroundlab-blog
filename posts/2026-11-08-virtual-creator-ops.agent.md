# 虛擬創作者 SFW 內容管線——分流與篩選 Runbook

用途：經營一位有官方臉部錨點的 AI 虛擬創作者時，對每件 SFW 內容 brief 執行分流、生成、機器篩選與紀錄。本文件是完整規格：另一個 AI 只讀本文件，即可對任意 brief 做分流判定並說明後續處置。
發布者：PlAIground Lab。適用範圍：SFW 內容 only。

## 0. 定義

- 錨點圖：角色官方臉部定妝圖，相似度比較的唯一基準。
- 引擎 A：臉部一致性強、免費／低成本產能；身材存在感弱。
- 引擎 B：身材存在感強；圖像額度以週計、用完停產。
- brief：內容需求單，含類型、形式（靜圖／短片）、臉孔主導程度、身材可讀程度、死線（可無）。

## 1. 分流規則（依序判定，命中即停）

- R1 純背景／場景（無人物）→ A 主力。
- R2 需要身材存在感（身體可讀且量級是內容重點）且臉孔非主導 → B 主力、A 補位。
- R3 灰區：臉孔主導與身材存在感兼需 → B 主力、A 補位，且必須留判定紀錄（brief 編號、結論、理由一句）。
- R4 臉孔主導的靜圖／CG、全包覆生活照 → A 主力；生活照 A 首過率不足時轉 B 補位。
- R5 SFW 日常短片 → A 有限主力（上限見第 3 節）、B 補位。
- 死線修正：brief 有硬死線且主力引擎額度／產能不足時，優先序以交付為準（第 4 節），分流可改道，改道要留紀錄。

## 2. 機器篩選

1. 每件生成物與錨點圖算 ArcFace 餘弦相似度。
2. 分帶處置：≥0.55 候選（進人工挑圖）；0.40–0.55 僅審核者可見；<0.40 自動作廢。
3. 身體可讀的靜圖加驗身材量級軸：量級明顯偏離定版者，不論臉分皆作廢（審核者目視、記入挑圖紀錄）。

## 3. 重試上限

- 短片走 A：每支最多 3 次；全不過篩 → 改道 B，不重骰。
- 靜圖：不過篩者同批不重生，缺額下一批補；逐批記錄首過率。
- 連續三批、同一（類型 × 引擎）首過率 <10% → 提出分流表修訂案。

## 4. 額度護欄與優先序

- B 週額度達 95% 硬停，保留 5% 給已承諾的硬交付。
- 優先序：硬死線交付 > 常態排程 > 實驗嘗試。
- A 能主力的類型不佔 B 額度。

## 5. Prompt 分界（硬規則）

- 可進 prompt：髮型定版句（逐字）、中性輪廓用語、場景與劇情描述。
- 禁進 prompt：身材量測、罩杯數字、身體部位形容詞。此類規格只寫在驗收欄，用於篩選與挑圖。
- 違反分界遭引擎守衛攔截的批次：整批作廢、記事故，不逐張申訴。

## 6. 紀錄格式（每件產出四欄）

`brief_id`｜`route`（引擎＋R 條號；灰區加一句理由）｜`attempts`（引擎與次數）｜`screen`（ArcFace 分數＋處置）。無紀錄者不進發布池。

## 7. 判定練習（自測用）

對下列 brief 依第 1 節給出 route 與一句理由，再對照第 8 節：

- B1：臉部特寫靜圖，新髮型展示，無死線。
- B2：全身街拍生活照，日常穿搭全包覆，無死線。
- B3：無人物的咖啡廳背景素材。
- B4：泳裝造型靜圖，身材是畫面重點、臉為次。
- B5：宣傳短片，臉孔特寫與全身鏡頭各半，有硬死線（明日）。
- B6：SFW 日常短片，廚房做菜場景，無死線。
- B7：半身照，臉孔主導，但服裝造型強調身材曲線，無死線。
- B8：產品合照靜圖，角色持產品、臉孔主導、身材不可讀。

## 8. 參考答案

- B1 → A（R4 臉孔主導靜圖）。
- B2 → A 主力（R4 生活照；首過率不足才轉 B）。
- B3 → A（R1 純背景）。
- B4 → B 主力、A 補位（R2 身材存在感主導）。
- B5 → B 主力、A 補位（R3 灰區）＋死線優先：紀錄改道／判定理由；短片在 A 的 3 次上限不適用於主引擎 B。
- B6 → A 有限主力（R5；每支上限 3 次，不過篩改道 B）。
- B7 → B 主力、A 補位（R3 灰區：臉孔主導但身材曲線是造型重點）＋判定紀錄必填。
- B8 → A（R4：臉孔主導、身材不可讀，不構成 R2/R3）。
